A deadpan one-star review of sleep, an everyday essential, in a single line
of 160 characters or fewer.

## Entry

> One star. Sleep takes eight hours of my day and returns me with a sore neck and the same problems. Would not recharge again.

## How it works

`main.ts` is a self-contained Node 22 program (stdlib only). It writes the
review to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, or
`/output`).
